业务端只接收`business_files`：第一阶段一份19列基础资料Excel；明确收到并承接日方实际价格更新后，一份计算审核Excel；计算明确确认通过后，两张受控草稿。旧阶段文件移到后台保留，目录不递归当作业务交付。源/版本/日志/测试/采购附表/待核清单都留后台，不要求同事另填表。

`upload`自动做版本识别、原A03或计算预览。默认基础计划提出具体非空有效E/F/M/O/P范围供一次确认，未变已确认不重选，采购价只有明确原单位/来源才纳入确认，材质默认不确认；用户限定范围时用原A03 selection合同。不从Excel自行宣布批准，必须展示列/行范围及待核项，再以本次确认ID和用户明确回复提交。CAS、幂等、保留专业审批关闭等原规则不变。更新附件形状不能证明是实际采购价，须用户说明及范围确认。

本机入口：`python -B run.py --config <后台/session.json> --request <后台请求.json> --result-file <后台结果.json>`。用户只用自然语言及附件，宿主编排请求，不让用户写JSON/命令。请求动作start/current/upload/confirm见候选Skill引用合同。配置mode与后端business/synthetic必须相同；模拟状态和文件全部留后台测试。
