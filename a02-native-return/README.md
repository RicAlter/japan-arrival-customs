# A-02 原表人工修改回传与差异预览

独立候选版本 `0.2.0-a02-preview`，基于 A-01 `3ccbc76`。只提供原表回传预览，不调用业务版本保存、B2 commit、D1 或任何计算入口。原 A-01、rc.5、P3-A/P3-C、旧 B2 和 `confirmed-arrival-v1` 均不修改。

## 运行

使用已有 Python / openpyxl 3.1.5，在此目录独立进程运行：

```powershell
python -X utf8 -B -m native_return --request request.json --output 一个不存在的新目录
python -X utf8 -B -m unittest discover -s tests -v
```

`request.json` 只允许：

```json
{
  "context_file": "宿主维护的当前批次上下文.json",
  "uploaded_file": "同事回传.xlsx",
  "box_corrections": [
    {"sheet": "Sheet1", "cell": "H17", "pieces_per_box": 6, "message_ref": "真实对话出处引用"}
  ]
}
```

盒规对话提案可省略。不得伪造对话内容或将测试出处当业务依据。提案只记录原行及拟每盒件数，不写 Excel，不批准采用，不推断 Qty 单位。

宿主上下文只允许以下字段，不能从 Excel 读取批准身份、批次声明或版本：

```json
{
  "schema": "a02-trusted-context/1",
  "current_output": "当前已发出A-01结果目录",
  "business_batch_id": "当前批次",
  "export_id": "与当前A-01登记一致的导出ID",
  "a_version": "与当前A-01登记一致的A版本",
  "known_outputs": ["宿主维护的全部相关已发出副本目录，包含当前及旧版本"]
}
```

A-01登记、工作副本及原件摘要必须全部有效；运行前后重验上下文、原件、副本和上传摘要。`known_outputs` 是受信宿主管理的完整已发出登记集合，不是允许业务自行删减的跳过校验选项。此模块只读取上下文，不实现当前版本推进或确认保存。

## 比较与返回

对比基准为发出的工作副本。复用 A-01 已验证表头映射和源行 ID、B2 排他 SHA 归档及原子 JSON；不将原表送入旧 B2 三页解析器，也不伪称复用了其提交接口。

16列版只允许 E/F/M/N/O/P、无原公式的 G/H，以及 C 改码提案、原格为空的 B 补值提案。其他已验证格式按其 A-01 字段登记比较，不根据列字母猜测。YD 可清空。G价格需核实币种/单位/来源；H数字为正整数每盒件数，仍未批准。材质始终是参考，编码修改保留原行 ID 并要求进一步明确对应。

任意原公式、原数量、金额、日方单价、箱号、JC、日文原名、表头、附页/箱重值及公式受保护；改动则整份拒绝。新增公式、插删行、新增/删除/重排页签、合并范围、命名区域和原批注改动也拒绝。普通样式、颜色、列宽、筛选视图和元数据不构成确认。只读骨架无法区分的重复行修改标为范围待核，不推断排序后的归属。

正常 Excel 保存造成的公式缓存变化只留后台，原公式仍须相同；不采用回传缓存。已有外部链接只按登记内容静态核对，从不访问目标；新增、改写或删除链接拒绝。存在其他不支持的活动对象/特殊公式时保守拒绝。

成功结果示例：`修改了12格，3格需要进一步确认；仅预览，尚未确认保存`。3格指额外缺项/范围问题；其余9格也没有获批。`confirmed=false`、`a_version_saved=false`、`can_enter_b=false` 始终成立。黄色未修改、仅改色及重复提交都不产生确认。

`result.json` 为最终资格标志；`technical/preview.json` 保存差异和来源、H分组、未动候选及缓存记录。用 `read_preview` 校验预览摘要和回传归档后展示。拒绝结果包含工作表与单元格位置，没有可用成功预览；晚失败预览隔离为 `ineligible-preview.json`。输出中不生成新的业务工作簿、说明页、字段或批注。

## H列和版本边界

原 H 的 G÷K 公式属于价格比值，不是每盒件数独立证据；整组标识，不能因红色有很多格就要求逐格重填。原正整数仅为观察/候选，空格不默认1，不需要换算时不制造必填；本轮不判断全批实际缺盒规依据总数。更正公式格时保持公式原样，通过对话形成后台待确认提案。

因为获批版式没有嵌入版本ID，回传只能在宿主已登记集合中按只读内容唯一匹配。明确旧副本、其他批次或同时匹配不同版本均拒绝；不能凭文件名、时间或请求指定ID猜版本。**未登记的旧文件若与当前只读内容完全相同，单凭Excel无法证明其来源。** 宿主必须保留完整已发出登记；存在歧义时取当前副本重新修改。本轮不声称实现跨宿主的完整文件认证。

尚未实现：正式确认保存、并发版本提交/幂等业务回执、拆分合并、A→B实际适配及计算、WorkBuddy原生接入。既有 B2 版本存储能力保留，待后续授权新增 A 提交适配。本轮测试是合成及授权历史表程序模拟编辑，不是实际同事审批或独立新批验收。
