## 一、计算基准与启动条件

1. 使用本批确认的实际“卸価額”和对应货单版本、币种及总额。原UnitPrice及其原金额保留备查，不覆盖原件，不在卸价缺失时自动顶替。
2. 先核对商品身份、原计价单位、数量关系和整票覆盖。4250原UnitPrice与2630卸价选错造成的差额属于来源错误，不是可以分摊的尾差。
3. 采购成本按实际购买单位保留。例如到货1盒、每盒10包、每包2张：采购按10包及每包价计成本，海关按20件表达数量。不能为了配报关金额改包价或实物数量。
4. 整票所有应计商品的数量、价格和单位均完整，货单明细与目标总额吻合，才允许整票尾差处理。部分行可算时保留部分结果，不用部分合计去凑整票总额。
5. 本策略采用整数日元海关基础单价。目标总额不是整数日元、币种不是本次确认的JPY，或来源/单位有冲突时，保留草稿交业务处理；不自动换汇或取整目标总额。
6. 零金额合法商品可以按来源保留，但不参加尾差分配。未知、缺失和错误值不能用0替代。

设货单目标总价为T，行海关数量为q，基础整数海关单价为p，基础行金额为q×p。全部数值以精确数表达，不用浮点近似判定对账通过。

**D＝T－Σ(q×p)。**

- D=0：不调整任何行，标记价额已对齐。
- D<0：基础报关总价偏高，只允许减价。
- D>0：基础报关总价偏低，只允许加价。

## 二、候选行的确定

仅本次新报关草稿中的自动计算行可以成为候选，必须满足：

- 实际卸价来源可靠，商品及规格范围明确，没有未解决的价格、数量或单位冲突。
- 海关数量为明确的正整数，海关单价与其计数单位一致，基础单价为正整数。
- 海关单价和金额未被人工锁定；已有人工确认的海关价额不自动调整。
- 非赠品、非零价商品。减1后价格不得为0或负数；加1后仍须满足该行现有可用价格约束。
- 不需要改变采购成本、原数量、包装关系或原始价额，才能完成本次调整。

H采购参考价缺失不单独构成排除理由：已有可靠实际卸价及其他必要依据时，可纳入候选。不能把“原H缺失”与“实际卸价缺失”混成一个问题。

未调整或不具备候选资格的行，按其既有确认/基础结果保留。它们仍参与应计货单总额核对，但不会被自动分摊尾差。

## 三、选行顺序

对所有精确可解组合按下列顺序比较，前一项优先级高于后一项：

1. **调整行数最少**：一行可精确抵消就不选两行；两行可解就不选三行。
2. 同样行数下，**优先无需多层换算的本体单品**：最小化选中组合中的包装换算商品行数。是否本体单品使用本行已有明确业务分类/包装依据，不能为取得优先级而猜测。
3. 仍相同时，**相对价格影响最小**：最小化Σ(1日元÷该行基础单价)。使用精确比值比较，不能先把这些比值取整。
4. 仍相同时，**按原工作表顺序和原行号确定**：比较选中原始行坐标的有序列表，取最早者。同输入重复运行必须选择同一组合。

不固定选择历史704/1917行，不按当前文件最后几行倒推；也不只是挑数量最大、金额最大或首先遇到的行。

## 四、只同向、每行最多1日元的精确匹配

1. 设s为D的符号：D>0时s=+1，D<0时s=-1。
2. 每行只有“未选中”和“选中”两种状态。选中后最终单价=p+s；每行只能选中一次，不连续加减多次。
3. 选中行金额变化=q×s。要求选中候选的数量之和恰好等于｜D｜。
4. 只同向调整，不通过某些行加价、另一些行减价对冲；即使这种对冲在数学上可解，也不属于本方案的自动处理范围。
5. 数量大于｜D｜的行不能在本次同向组合中使用。先检查候选数量总和及公约数等明显不可能条件，再进行精确0/1组合匹配。公约数满足条件不等于一定可解。
6. 后续实现使用逐行0/1动态规划或等价的精确组合算法，保存每个累计调整额的最优组合，按第三节完整优先级比较；同一行不能在同一状态链复用。禁止用贪心、四舍五入或近似求和代替精确匹配。

找到精确组合后，逐行生成最终报关单价和金额：

**最终单价=p+s；最终行金额=q×最终单价。**

未选中行保持基础单价和金额。每行金额重算须与最终显示单价、数量一致，不能只改合计或公式缓存。

## 六、无解与需业务处理的情况

以下情况不自动放宽限制、不标记最终价额通过：

- 依照已确认的同向、每行最多1日元约束，没有精确组合。
- 只有修改人工锁定价、赠品/零价、实物数量或原采购成本才能匹配。
- 需要把有价商品减为0或负数，或突破已有明确的单行约束。
- 目标总价非整数日元、卸价来源不明、计价单位冲突，或整票应计行尚未齐全。

保留原草稿、已核事实、候选排除原因和剩余差额，交业务处理；自动尾差分配不采用任何近似组合。不能因计算或资源限制提前结束，就声称数学上已经证明无解，须区分“无精确解”和“未完成求解”。

例如只有20件，基础每件50日元、目标1001日元，D=+1。整数单价每调整1日元，金额变化20日元，不可能自动补足1日元；保持草稿，最终价额核验不通过。不自动改成两位小数、扩大为±2日元或改数量。

## 八、最终验收条件

1. 每行最终金额＝该行最终显示单价×对应海关数量，单位一致。
2. 全部应计行的报关金额合计＝确认货单目标总价，剩余尾差严格为0。
3. 被选中行只沿同一方向调整1日元；未选中行不变，所有原数量和原采购成本不变。
4. 所有调整可追溯，原始/人工内容、公式、原图和旧结果保全。
5. 无解或条件不足时保存待核草稿，不标记最终价额完成；其他业务/专业验收也不因价额对齐而自动通过。

这里“每行对上”指每行最终金额与其最终显示价×数量相符。调整行允许不同于原货单相应行金额，其差异明确记录；整票总额必须对齐。不能同时把每个原行金额锁定，又要求用跨行调价消除尾差。
