# P2申报归类决策学习（待实施目标）

本页保留学习目标。0.6.0已实现B2本地回传及[D1独立事件决策库](p2d1-library.md)，见 [实际回传](p2b2-return.md)；自动复用仍未上线。后续顺序：模式/候选规则回放与冲突检测→授权发布及自动采用→更多飞书官网只读来源。

1. 官方材质、历史参考材质、AI推荐申报材质、人工最终申报材质四层独立保存。完整原文和全部组成留作事实，不把官网文字直接当申报选择，不覆盖历史。
2. 人工最终选择关联类型、用途、组成/构造、关键材质、版本/规格、归类理由/证据、税号/税制版本、税率及有效日期/条件。修改或采用都保留原推荐、新选择、原因、凭据、可信执行者及范围。缺关务等必要审签可以存草稿，不能成为正式学习依据。
3. 现有未审核Excel仅候选。自动结果不当新增人工支持；一次成组确认多行不伪计多次独立决策。多次有效人工审核才可发现候选模式，不因一次选择推及全部相似商品。
4. 不同JAN可按类型、用途和关键材质/构造等检索历史决策。相似案例只能推荐；经回放、留出验证、冲突检测和授权发布的有效规则，才能在全部适用条件明确满足时自动采用最终申报材质及有效归类，无须逐件再选。此自动执行授权不能伪记成本批人工审签。
5. 相似度不足、用途构造不同、事实未知、历史冲突、税率失效、缺必要依据或规则未发布/撤销，留待人工。阈值、样本量、质量门槛和发布权限须授权配置，未配置不自动发布。
6. 纠正新建版本，获批后积累；规则可修订、暂停、撤销和回滚，回滚仍须校验当前有效性，不改历史锁。人工最终选择/归类依据改变时重新核验对应税号税率及盒装税金；单纯追加参考不自动覆盖最终值。
7. 业务Excel继续总览、问题、明细，日常仅展示当前最终推荐、依据、归类税率有效提示、自动匹配状态和例外。详细决策史在后台，身份不从Excel获取，不恢复24个申请栏。盒规箱规保留本批准确计算校验，不作历史学习主线。

验收看不同JAN新商品自动覆盖、自动材质准确率、税号/税率适用联合正确率、人工纠正率与决策商品数，以及人工纠正并授权修订后后续同类商品是否减少重复决策。须有有效人工裁定和独立复核样本；旧表复现不是归类正确率。D05、尾差、身份映射和未知盒规门禁继续有效，最终正式业务产物仍只有海关报关单和内部到货单。
