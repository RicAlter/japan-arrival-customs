# P3-C 第一阶段：KMT1002原始附件到运营输入候选

独立候选，复用P3-A `f420951`、原rc.5 raw importer / preliminary / operations adapter、P1/P2-B只读查询和原数学助手。没有改动这些模块、B4/D1或正式门禁；不安装WorkBuddy，不访问五站。当前入口是独立Python CLI，不能称WorkBuddy已接通。

## 准备入口

从本目录用独立Python进程运行，沿用现有依赖及仓库相邻目录结构，不混载在用Skill：

```powershell
python -X utf8 -B -m raw_operations --request <私有来源请求.json> --output <全新隔离目录>
```

请求只接受：

```json
{
  "batch_id": "KMT20261002",
  "raw_file": "<原始invoice.xlsx>",
  "business_file": "<第3步业务来源.xlsx>",
  "declaration_file": "<第4步申报准备.xlsx>",
  "library_config": {"database": "<兼容的只读静态B4或P2-B副本.sqlite3>"}
}
```

第3＋4步可均不提供，程序仍生成原始初步整理与参考候选并报告缺失衔接；不可只传其中一份。它们是已有运营上下文，不是系统从原invoice自动推导的确认资料。已有人工注释的来源原样保留，不能称未经补充的纯原件。只支持本轮KMT1002范围，不扩展KMT0802/SCC。

`technical/`保留原始观察、现有初步整理工作簿、库候选、物流核对、运营输入候选、精确来源链接和换算确认范围。初步整理通过既有导出器保存并重开验证；候选状态可显示，值不复制到已确认商品/材质字段。无来源的单位/名称/材质继续空缺。F/备注/YD及公式/缓存证据沿原适配器保留，不写入系统说明。

## 关键边界

- 原invoice零售价/Subtotal与第3步业务金额各有来源，不能互相覆盖或用零售/历史答案倒推业务金额。
- 仅唯一箱号＋编码建立源行链接。同码仍不代表身份批准；名称/数量不同单列当前来源差异。名称仅两端空白不同留作格式证据，不要求业务重复确认，不改源值；不模糊匹配或剥除版本/标点。未对应、重复键、无码行不按名称近似或最终答案推断改码/拆行，不丢行、不排序。
- 特殊换算按当前申报/业务数量比、内部数量/盒数及源文件/表/列归组；每组保留全部行、原始单元格、范围哈希和未配对提示。它是本批待确认关系，不是从品名猜盒规、发布通用规则或替未配对身份确认。业务按组处理，不要求逐行重复填。
- P1查询排除本批来源ID与文件SHA；P2-B复用只读接口后，剔除本批事实再重算，不采用包含待测事实的预计算摘要。无法隔离来源的人工维护事件/纠正记录直接阻断，不能混作独立参考。已知来源屏蔽不等于排除所有未知转抄或开发暴露，因此只称历史回放。
- 查询候选/长期版本或规格缺项保留后台，不覆盖当前运营值，不自动升级材质/身份，不把全部库问题变成当前业务待办。
- **本阶段只准备待确认输入，不接收确认参数、不生成已确认三页模板或两张结果表。**返回`needs_confirmation`或`needs_input`，`can_enter_pair_calculation=false`；实际业务异常总数、人工输入量保持null，`business_files=[]`。没有虚构确认、自动调价、税率补造或伪成功。HS/关务依据/日期不额外成为本准备步骤前置，正式门禁保持原样。
- 失败返回`validation_incomplete`，不暴露成功准备文件或半份结果，诊断留新目录。原件/库/依赖变化使结果失效。不能覆盖原目录重跑。

## 验证与评分

```powershell
python -X utf8 -B -m unittest discover -s tests -v
python -X utf8 -B validate_private.py --config <私有验收配置.json>
```

合成测试只验证保护行为。私有历史验证配置包含上述来源请求字段以及`output`、`report`、`protected_files`（文件绝对路径到SHA的对象）和`answer_customs`。准备入口不接收答案参数；验证程序先完成准备、调用原rc.5数学助手做未确认算术预览并锁定哈希，然后才打开隔离历史答案评分。差异不会回写输入、执行价或引擎。算术预览不能算单位确认、税金、双表生成或保存格式通过。

后续必须补齐来源对应与本批必要确认，再经原运营入口/原计算/双表完整核验才能交付两张受控草稿。本阶段没有开发新的审核系统或自动确认接口。历史回放与独立新批次验收分开，未观察真人时人工操作与工时保持未验证。

私有原件、库、参数、来源/确认范围、候选、初步工作簿、答案和报告不提交GitHub。回滚仅停用本目录的新入口，原P3-A、rc.5和各库无需恢复；失败保留`result.json`、`technical/failure.json`和来源哈希，下一次使用新目录。
