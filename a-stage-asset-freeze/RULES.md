# 本轮固化规则（2026-11-05）

## 字段语义与匹配

1. E商品名称来自来源“品名/商品名称”；F规格来自“SKU/单品名称/角色款式”。JAN和YD都一致只证明记录对应，不能证明取错的字段正确。不得用单品名称填商品名称。
2. 名称必须在同一来源记录中JAN和YD同时一致；不因相同YD把别的编码的名称搬来，不以跨记录拼接补成精确证据。无依据继续空白。
3. 源编码DG+JAN可以支持本批YD参考；不用于名称、价格、盒规或采购数量推导。保留原码和JC。
4. 当前用户明确纠正或新截图可在对应商品范围覆盖旧展示文字，保存旧原文、截图出处、差异和适用JAN；不推广到未指明商品。

## 材质与品类

1. 供应商同YD链接可能只在一行写该链接全部商品的材质集合。原文、坐标、JAN/YD与商品类型分别留存。
2. 按本行日文商品名和规格识别具体商品类型，再在已授权链接材质范围内选择有依据的材质；不把整组材料当每款的组成，不自动跨YD或版本复用。
3. 用户举例的透卡PP、吧唧马口铁、贴纸/亚克力吧唧亚克力须在本链接资料支持及具体品类可识别时作参考；不得用一般常识覆盖纸/PP等不同来源。材料范围仍不清时保留完整原文红色待核。
4. “纸/PP”“PVC/铁”等有多种解释时，不凭词袋拆成唯一材质，也不遗漏可能的复合组成。商品类型参考不是HS/税率决定，材质参考不是最终申报材质。

## 保存与交付

**2026-11-05最新列分离约定**：原品类/材质列供人工填写，已有人工值必须保留。助手填写的品类/材质放在表尾独立“AI参考品类、AI参考材质”两列，原文与来源继续后台保留。不得把助手参考占作人工结果，不自动复制、采用或批准。当前16列来源的已登记工作副本可附加Q/R两列参考装饰，原M/N仍可人工编辑，参考Q/R只读；筛选延伸至B:R。这不表示通用18列原件导入器已实现。原人工列本来为空时，把助手曾写入的参考移出并恢复原空值；不得据此清空其他批次或同事已填内容。A03只保存原人工字段的明确编辑，参考列不进入人工确认字段集或B计算。

黄色为参考，红色为真正缺项或待核；名称/规格/渠道空值及合法YD空缺不统一标红。人工金额调整色高于取整色。价格差阈值沿用当前已登记A规则，不借本轮固化改变。

16列来源的原始业务区B:P，C/E/F/G/M/N/O/P可编辑；本轮附加参考列后的登记副本筛选B:R。原数量金额、公式/cache、箱重和其他页签受保护。22列沿用独立既有布局合同，不硬套16列坐标。

发出底稿重新登记须新版本、新摘要、独立不可变基准及可信宿主版本识别。登记不是人工采用或专业批准。A03保存仍须预览和指定范围；不得重置已有真实保存。固化不开放B计算、拆分合并或正式海关双表。
