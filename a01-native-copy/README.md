# A-01 同版式工作副本与副本登记

独立候选`0.1.0-a01`，仅新增本目录。复用冻结rc.5原表读取器、P0 OOXML解析、P1只读商品查询、B4只读结构检查及B2快照/原子JSON保存。原rc.5、P3-A、P3-C、旧接口和正式门禁不修改。

## 入口

在本目录以独立Python进程运行：

```powershell
python -X utf8 -B -m native_copy --request <私有请求.json> --output <不存在的隔离目录>
```

请求结构：

```json
{
  "batch_id": "NEW-BATCH-001",
  "input_file": "<已授权的原表.xlsx>",
  "library_config": {
    "database": "<兼容B4基础v3、来源V1的静态只读库>",
    "allowed_source_ids": ["<本次明确允许的参考来源ID>"]
  }
}
```

`library_config`可省略，仍可生成原值工作副本；空缺保持未知，不假称完成资料匹配。有配置但库失效、版本不兼容、有活动日志或来源不合法时不发布副本，不初始化、迁移或修改原库。不存在采购MCP、网站、远程写入、资料库维护或D1调用。

不限制批次名称，不从文件名硬编码KMT1002。原P3-C入口仍冻结；新批使用本独立入口，不修改旧桥接器。

## 经过验证的格式边界

1. 原rc.5支持的`invoice (計算)`第17行两种明确表头布局：`kmt-raw-invoice-v1/v2`。
2. 用户提供的16列表头布局：A箱号、B原产地、C编码、D/JC、E商品名称、F规格、G采购单价、H盒规、I日文名、J数量、K日方价、L金额、M品类、N材质、O渠道、P/YD。
3. 原第3步映射的已验证布局：关键表头完整，D:H空表头锚点、P为YD/yd。G/H无明确表头时不填，也不把旧H比值当每盒件数。

需要已有`重さとサイズ`或`重さとサイズ (2)`内嵌箱重页。此阶段未增加任意模板、外部箱重附件合并、0802缺表头修复或SCC适配。文件不匹配时明确拒绝，不猜列。原始来源可能已有人工整理，本入口不认证“纯日方未加工原件”。

## 补填和保全

- 只填已映射的空业务格，不覆盖任何非空值（含0、空白字符串内容或已有公式），不更改编码/原数量/原单价/金额/箱重，不新增业务列或页签。
- 使用P1只读查询；仅单一非冲突候选的有证据字段可作黄色参考，未知版本不伪称身份确认，多候选/冲突不选第一条。无码行保留，不猜JAN，不强制填YD。
- 名称/规格/品类/渠道/YD及完整材质来源可作为参考；采购价须来源同时明确JPY和采购单位。盒规只接受明确结构化“盒→件/个”关系，不从品名、BOX或“全n种”推算。
- 用户确认H数字表示每盒件数，但每行H值仍未获本批采用。已有H非整数或其公式缓存非整数时只标待确认，公式和值不改；Qty单位始终未确认，不进行任何换算。
- 空中文名/品类/材质或明确字段冲突可标红；不知道的内容留空。无YD不标红。已有非空业务字段不会因历史候选冲突被覆盖或统一转成待办。
- 已有人工/模板底色不清除；需要新标色但原格已有底色时保留原色，并在后台登记`fill_applied=false`。原色不等于本程序已确认。业务表不写任何问题说明、来源、版本或哈希。
- 同批来源/原件哈希及已知答案/最终来源先排除，再解析候选。显式来源白名单不是完整历史去污染证明，本轮只称参考候选，不声称独立新批准确率。

使用标准库对原ZIP中的目标单元格作局部补写；其他包成员字节不变。原样式定义保留，只追加底色样式并保留字体、边框、格式和对齐。独立核验器把计划单元格还原后比较整张原表，检查所有其他格、原行序、公式及缓存、布局和所有箱重部件；再重开验证。没有全工作簿另存造成的公式缓存丢失。

## 交付、登记和失败

成功时`delivery/`只有一份原名称加“工作副本”的Excel。`technical/`保存来源候选、字段状态、具体补填/标色、保全核验、原始批次快照和`export-registration.json`。

登记绑定原件、工作副本摘要、每个源行/单元格、预填来源、字段候选状态、A版本、导出ID和程序/依赖版本。`result.json`成功提交才激活登记；晚失败副本进入本次技术隔离目录，不返回业务路径。输出目录必须全新，不能覆盖旧副本；成功副本可以通过`registered_copy()`只读重核登记与文件，尚不是回传接口。

运行登记使用`a01-native-copy-registration/1`，对应设计接口的`register_copy`子集：业务批次、来源清单/摘要、原表映射、行对应、候选快照、A版本和导出ID均保存。它不冒充完整`a-original-return-design/1`，不生成`confirmed-arrival-v1`。

始终`confirmed=false`、`can_enter_b=false`、`formal_output=false`。业务异常总数、实际人工量及工时保持null；补填格数/标色格数只是本次文件操作计数，不能换算节省工时。
